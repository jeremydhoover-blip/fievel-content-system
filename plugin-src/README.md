# Fievel

**Your AI content systems architect.** Fievel helps content designers, UX writers,
conversation designers and AI experience designers build a portable content
system with their coding agent: product context, writing standards, knowledge
sources, AI behavior rules, quality checks and ownership, saved as readable
files you own.

## Skills

| Skill | Use it to |
| --- | --- |
| getting-started | Start or resume Fievel and choose a beginner, existing-guidelines or AI-experience path |
| content-system-builder | Build product context and content standards from your decisions and approved sources |
| source-discovery | Inventory and assess sources, keeping their authority and provenance |
| ai-behavior-designer | Define AI responsibilities, action boundaries, uncertainty and recovery |
| evaluation-designer | Create quality checks, check saved responses and prepare human review |
| content-audit | Review an existing Fievel system for gaps, conflicts and coverage |

Start a new chat in your project folder and ask Fievel to get started. A
fictional practice example is included, so you can try it without company data.

## Requirements

Python 3.10 or later. Fievel checks for its one dependency (`jsonschema`) and,
with your permission, installs it in a `.fievel-venv` folder in your workspace.

## Your data

Fievel's tools run on your computer and make no network requests. Your project
files stay in the folder you choose; nothing is saved inside the plugin. What
you share in the conversation is handled by your coding agent under its own
terms. See the [privacy policy](https://jeremydhoover-blip.github.io/fievel-content-system/privacy.html).
